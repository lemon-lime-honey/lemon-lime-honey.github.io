비전 감지 데이터와 텔레메트리 데이터 간의 정밀한 시간적 동기화를 보장하고, 서버 단에서의 노이즈 필터링 성능을 확보하기 위해 백엔드 파이프라인을 고도화했다.

## [Java / API] 비전 주도형 이벤트 그룹화 및 사전 필터링

- 원시 텔레메트리 데이터에는 정차 상태나 초저속 주행 시 발생하는 무의미한 센서 노이즈가 다수 포함되어 있었다.
- 저속 및 정차 상태에서 발생하는 무의미한 데이터를 선제적으로 버리기 위해 속도 기반의 사전 필터링 로직을 백엔드에 적용했다.
- 큐 기반의 비전 감지 버퍼링 구조를 도입하여, 차량의 조향이나 제동 조작이 카메라 시각 감지보다 다소 지연되어 발생하더라도 이를 단일 이벤트로 병합하는 알고리즘을 구현했다.
- 복합 이벤트 쿼리 수행 시 원시 감지 로그 대신 정제된 객체 위치 데이터를 직접 조회하도록 변경하여 방위각 기준의 필터링 정확도를 확보했다.

## [Rust / Analytics Worker] 타임라인 오프셋 동기화 및 지연 시간 추출

- 주행 기록 장치와 비전 카메라 간의 하드웨어 타이밍 오프셋으로 인해 분석 워커가 잘못된 타임라인을 참조하는 버그가 있었다.
- gRPC 프로세스 요청 페이로드에 비디오 및 텔레메트리 오프셋 필드를 새롭게 추가하여, 발생한 타임라인 편차 정보를 분석 워커에 정확히 전달하도록 수정했다.
- Rust 워커가 InfluxDB에서 시계열 데이터를 쿼리할 때 전달받은 오프셋을 역산하여 주입하도록 처리함으로써, 완벽하게 정렬된 타임라인 동기화를 달성했다.
- 타겟 이벤트 발생 시점(T0)을 기준으로 운전자의 제동, 가속 페달 릴리즈, 조향 지연 시간을 각각 개별적으로 추적하여 정밀한 반응 속도 지표를 산출해 내도록 고도화했다.
