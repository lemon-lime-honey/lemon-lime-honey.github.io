데이터 분석가들이 주행 통계 및 위험 이벤트 분포를 다양한 각도에서 검토할 수 있도록, 클라이언트 사이드 기반의 동적 대시보드와 유연한 시각화 파이프라인을 구축했다.

## [React / Dashboard] 통계 대시보드 및 다이나믹 차트 빌더 구축

- 기존의 정적인 리포트와 달리, 사용자가 원하는 지표를 동적으로 구성하고 조회할 수 있는 대시보드가 필요했다.
- JSON 페이로드를 기반으로 차트의 구성을 동적으로 조립하고 렌더링할 수 있는 범용 차트 컴포넌트를 도입했다.
- 정규 분포(Normal Distribution), 커널 밀도 추정(KDE), 누적 분포 함수(CDF) 등 전문적인 통계 분석을 위한 차트 포맷을 새롭게 지원했다.
- 상대 시간 정규화 기법을 적용하여 서로 다른 세션에서 발생한 이벤트를 동일한 타임라인 상에 올려두고 정밀하게 비교 분석할 수 있도록 구현했다.

## [TypeScript / Interaction] 다중 텔레메트리 구간 리사이징 인터페이스

- 사용자가 시계열 차트 상에서 여러 위험 이벤트 구간을 직접 편집하고 미세 조정할 필요가 있었다.
- 제스처 추적 라이브러리(`@use-gesture/react`)를 활용하여 타임라인 위에서 여러 구간을 동시에 드래그하거나 크기를 조절할 수 있는 다중 리사이징 기능을 구현했다.
- 픽셀 좌표 연산 중 무한대 값이 발산하여 렌더러 전체가 크래시되는 현상을 방지하기 위해, 초기화 단계에 방어적인 렌더링 가드를 적용했다.
- 인터페이스에서 드래그로 구간을 변경하면 즉시 API를 호출하여 백엔드의 분석 타겟 범위를 실시간으로 업데이트하도록 연동했다.

## [React / Architecture] 클라이언트 사이드 필터링 및 인증 연동

- 불필요한 API 왕복을 줄이고 사용자 권한에 따른 안전한 데이터 접근 제어가 요구되었다.
- 날짜, 세션, 이벤트가 포함된 계층형 트리 체크리스트 필터를 구축하고, 클라이언트 사이드에서 즉시 필터링을 수행하여 지연 없는 조회 경험을 제공했다.
- 전역 인증 스토어와 연동하여, 읽기 권한만 있는 사용자가 대시보드의 차트를 저장하거나 삭제하지 못하도록 물리적인 UI 차단 로직을 적용했다.
- 차트 선택 상자를 렌더링할 때 디바이스 픽셀 비율을 고려한 스케일링 보정 로직을 추가하여 고해상도 디스플레이에서의 화면 잘림 현상을 방지했다.
