주행 텔레메트리 데이터를 직관적으로 시각화하고, 분석가의 편의성을 높이기 위한 대화형 인터페이스 고도화에 집중했다. 고해상도 데이터의 실시간 렌더링 최적화와 사용자 경험 개선이 핵심 목표였다.

## [TypeScript / Visualization] 밀리초 단위 텔레메트리 차트 렌더링

- 차트 확대 시 축 정렬이 어긋나고, 불연속적인 센서 데이터로 인해 그래프가 계단형으로 왜곡되는 시각적 문제가 있었다.
- 속도, 가속도, 조향각 데이터에 이동 평균 필터와 스플라인 보간을 적용하여 궤적이 부드럽게 렌더링되도록 구현했다.
- 줌 인/아웃을 수행할 때 동기화된 여러 차트 간의 스케일을 강제로 정렬하여 시각적 불일치를 해소했다.
- 재생 중에는 차트의 패닝 기능을 차단하고, 사용자가 지정한 줌 레벨이 유지되도록 상호작용 제어 로직을 개선했다.

## [React / UI Component] 심층 분석용 썸네일 타임라인 인터페이스

- 전체 주행 기록 중 특정 순간의 상황을 미세하게 파악하기 위한 시각적 보조 도구가 부족했다.
- 밀리초 단위의 세밀한 구간을 분석할 수 있는 모달 컴포넌트를 신설하고, 텔레메트리 차트 하단에 썸네일 타임라인을 결합했다.
- Y축 스케일을 동적으로 조정하는 기능을 도입하여, 주행 속도의 변화폭에 맞춰 차트의 렌더링 범위를 자동으로 최적화했다.
- 차트 영역에서의 마우스 더블 클릭 이벤트를 가로채어 기본 줌 초기화 동작을 방지하고, 특정 시간대의 상세 분석 모달을 즉시 호출하도록 연동했다.

## [TypeScript / Analytics UI] 주행 이벤트 필터링 및 타임라인 오버레이

- 사용자가 특정 조건(예: 좌/우회전, 특정 속도 이상)에 해당하는 이벤트를 빠르게 탐색할 수 있는 기능이 요구되었다.
- 미리 정의된 주행 프리셋을 선택하거나 속도 및 조향각 변화율 같은 수치형 조건을 세밀하게 조정할 수 있는 전용 필터 패널을 구축했다.
- 백엔드 이벤트 추출 API와 연동하여 조건에 부합하는 구간을 찾은 뒤, 재생 진행률 바 위에 상호작용 가능한 마커 형태로 렌더링했다.
- 차트 툴팁에 인접 이벤트로부터 경과된 시간을 실시간으로 계산하여 표시함으로써, 상황 발생 전후의 인과관계를 원활하게 분석할 수 있도록 지원했다.

## [React / Map Display] GPS 궤적 및 공간 데이터 시각화 개선

- 기존 GPS 궤적은 단일 선으로 렌더링되어 현재 주행 위치와 과거 주행 위치를 명확히 구분하기 어려웠다.
- 전체 GPS 궤적을 낮은 투명도로 베이스라인에 깔고, 주행이 완료된 구간만 높은 투명도로 덮어씌우는 이중 렌더링 방식을 적용했다.
- 어린이 보호구역 등의 공간 폴리곤 데이터는 특정 줌 레벨 이상에서만 표출되도록 제한하고, 고대비 색상으로 렌더링하여 위성 지도 위에서의 시인성을 크게 향상시켰다.
