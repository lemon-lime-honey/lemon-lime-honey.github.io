이벤트 구간의 탐색 편의성을 높이기 위해 복합적인 필터링 인터페이스를 도입하고, 분석가의 시각적 피드백을 강화하기 위한 테마 엔진을 고도화했다.

## [TypeScript / Interaction] 복합 주행 필터링 인터페이스 및 타임라인 동기화

- 단순한 수치 필터링을 넘어 객체의 종류와 조향 상태 등 복합적인 조건을 조합하여 이벤트를 추출하는 기능이 요구되었다.

- 프론트엔드 스토어의 필터 조건을 백엔드의 복합 필터 페이로드와 완벽히 매핑되도록 API 전송 규격을 확장했다.
- 추출된 이벤트 구간과 비디오 플레이어 간의 시간적 불일치를 방지하기 위해, 오프셋 값을 직접 주입하여 동기화를 보정하는 로직을 구현했다.
- 심층 분석 모달 내에 타겟 분석의 실행 상태(대기, 진행 중, 완료, 오류)를 시각적으로 렌더링하여 파이프라인의 진행 상황을 쉽게 모니터링할 수 있도록 지원했다.

## [React / Theme Engine] 다중 컨텍스트 독립 테마 및 클래스 색상 매핑

- 레이더와 텔레메트리 차트가 동일한 테마를 공유하여 특정 지표의 가시성이 떨어지는 문제가 있었다.

- 레이더와 차트가 독립적으로 라이트/다크 테마를 가질 수 있도록 전용 스위치 패널을 신설하고 스토어 프로필을 분리했다.
- 객체 클래스별로 마커 색상을 개별 지정할 수 있는 팔레트를 도입했으며, 렌더러가 이 설정값을 실시간으로 구독하여 캔버스를 갱신하도록 구성했다.
- 기존의 평면적인 테마 설정을 새로운 구조적 형식으로 자연스럽게 마이그레이션하는 폴백 연동 구조를 설계하여 하위 호환성을 유지했다.
