프론트엔드 환경에서는 실시간 비디오 재생과 동기화되어야 하는 텔레메트리 차트와 공간 레이더의 성능 저하를 방지하기 위해 렌더링 아키텍처를 재설계했다.

## [TypeScript / Canvas] 레이더 렌더링 동기화 및 가비지 컬렉션 회피

- 다수의 감지 객체를 렌더링할 때 가비지 컬렉션(GC) 스파이크로 인해 비디오 프레임 드랍이 발생했다.
- `requestVideoFrameCallback` API를 활용하여 비디오 프레임 갱신 주기에 맞춰 캔버스가 렌더링되도록 동기화 로직을 구현했다.
- 텔레메트리 데이터를 `Float32Array` 기반의 평면 버퍼로 전처리하여 인메모리 객체 생성을 최소화함으로써 GC로 인한 일시정지 현상을 방지했다.
- O(1) 시간 복잡도를 가지는 양자화된 조회 테이블을 미리 생성하여, 비디오 재생 시 발생하던 좌표 매핑 지연 문제를 해결했다.

## [React / DOM] 차트 플레이헤드 커서 및 상태 렌더링 최적화

- 재생 진행률에 맞춰 텔레메트리 차트의 현재 시간 커서를 다시 그릴 때 과도한 리렌더링 오버헤드가 발생했다.
- 캔버스 전체를 매번 다시 그리는 기존 플러그인을 제거하고, DOM 요소의 `translateX` 속성을 직접 조작하는 오버레이 방식으로 커서 이동 구조를 전면 개편했다.
- 비디오 재생 중에는 리액트의 state 업데이트를 우회하고, 대신 `requestAnimationFrame` 루프 내에서 슬라이더와 텍스트를 DOM 참조로 조작하여 메인 스레드의 부하를 크게 줄였다.
- 비디오가 일시 정지되거나 종료되는 시점에만 리액트 상태를 동기화하여 렌더링 성능을 확보하면서도 컴포넌트 간의 데이터 일관성을 유지했다.

## [React / Map Display] 지도 타일 로딩 및 동기화 최적화

- 위성 지도 컴포넌트가 재생 프레임마다 불필요하게 갱신되거나 과도한 타일 요청을 발생시켰다.

- 지도 타일 렌더러를 무거운 최신 라이브러리 대신 Leaflet으로 회귀하여 불필요한 의존성을 덜어내고 렌더링 안정성을 확보했다.
- 최대 줌 레벨을 제한하고 페이드 애니메이션을 강제로 비활성화하여, 타일 로딩 과정에서 간헐적으로 발생하던 흰색 화면 깜빡임 현상을 제거했다.
- 비디오 재생 중에는 마스터 타임 구독을 완전히 해제하여 초당 60프레임에 달하는 무의미한 지도 동기화 호출을 차단하고 레이아웃 스래싱을 예방했다.
