차량 거동 데이터를 기반으로 주행 상태를 분석하는 엔진의 정확도를 높이고, 일시적인 데이터 통신 지연 상황에서도 전체 파이프라인이 오작동하지 않도록 방어 로직을 강화했다.

## [C++ / Kinematics] 거동 판정 임계치 최적화 및 상태 전이 구조 개선

- 차량 속도 및 이동 거리 임계치 설정 문제로 인해 회전 데이터가 유실되거나 상태 판정이 지연되는 현상을 해결했다.
- 정차 상태를 판정하는 속도 기준을 낮춰, 차량이 서행하는 동안에도 주행 궤적 데이터가 버려지지 않고 누적되도록 아키텍처를 수정했다.
- 후진 상태보다 정차 상태의 판정 우선순위를 높여, 기어 상태와 무관하게 실제 차량이 멈췄을 때 정확한 상태 전이가 발생하도록 논리 구조를 변경했다.
- 궤적 분석을 위한 최소 이동 거리 조건을 세밀하게 조정하여, 짧은 구간에서의 오판을 방지하는 동시에 조건 충족 시 즉각적인 회전 판정이 이뤄지도록 개선했다.
- 정차 직후 가속도 분석을 위한 속도 버퍼에 기준점을 강제 주입하여, 재출발 시점의 가속도 계산 오차를 제거했다.
- 상태 머신 상에서 좌우 회전 상태에만 타임아웃을 적용하고, 직진 및 정차 상태는 조건 달성 시 즉시 전이되도록 변경했다.

## [C++ / Data Processing] 통신 결함 허용 로직 및 타임아웃 아키텍처

- 네트워크나 하드웨어 지연으로 인해 데이터 수신 간격이 비정상적으로 벌어졌을 때, 과거 데이터로 인해 주행 상태가 잘못 판정되는 현상을 수정했다.
- 데이터 수신 간격이 임계치를 초과할 경우 내부 큐와 누적 데이터를 강제로 초기화하고 주행 상태를 무효 처리하는 방어 로직을 구현했다.
- 상위 레이어에서 타임스탬프 간격을 인위적으로 보정하던 코드를 제거하여, 물리적인 데이터 수신 지연 시간이 분석 엔진까지 투명하게 전달되도록 파이프라인을 변경했다.
