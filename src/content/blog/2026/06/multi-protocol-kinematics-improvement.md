차량 거동 데이터 기반 주행 상태 분석 엔진의 정밀도를 향상하고, 일시적 데이터 통신 지연 상황에서도 전체 파이프라인 오작동을 방지할 수 있도록 방어 로직을 개선했다.

## [C++ / Kinematics] 거동 판정 임계치 최적화 및 상태 전이 구조 개선

- 차량 속도 및 이동 거리 임계치 설정 오류로 회전 데이터가 유실되거나 상태 판정이 지연되는 현상을 수정했다.
- 정차 상태 판정 속도 기준을 하향 조정해 차량 서행 구간에서도 주행 궤적 데이터가 누락 없이 축적되도록 아키텍처를 변경했다.
- 후진 상태보다 정차 상태 판정 우선순위를 상향 조정하여 기어 상태와 무관하게 실제 차량이 정지했을 때 정확히 상태 전이가 발생하도록 논리 구조를 변경했다.
- 궤적 분석용 최소 이동 거리 조건을 조정해 단거리 구간 오판을 방지하고 조건 충족 시 즉각 회전 판정이 수행되도록 개선했다.
- 정차 직후 가속도 분석용 속도 버퍼에 기준점을 추가하여 재출발 시점의 가속도 산출 오차를 제거했다.
- 상태 머신상 좌우 회전 상태에만 타임아웃을 적용하고, 직진 및 정차 상태는 조건 달성 즉시 전이되도록 로직을 변경했다.

## [C++ / Data Processing] 통신 결함 허용 로직 및 타임아웃 아키텍처

- 네트워크나 하드웨어 지연으로 인해 데이터 수신 간격이 비정상적으로 증가할 때, 과거 데이터가 포함되어 주행 상태가 잘못 판정되는 현상을 해결했다.
- 데이터 수신 간격이 임계치를 초과하면 내부 큐와 누적 데이터를 초기화하고 주행 상태를 무효 처리하는 방어 로직을 적용했다.
- 상위 레이어에서 타임스탬프 간격을 임의로 보정하던 코드를 일괄 제거해 물리적 데이터 수신 지연 현상이 분석 엔진으로 그대로 전달되도록 파이프라인을 개선했다.
