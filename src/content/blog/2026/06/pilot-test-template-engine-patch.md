템플릿 파서 엔진 안정성을 끌어올리기 위한 마이너 패치를 배포했다.

## [Java / Template Engine] 타임스탬프 파싱 오버플로우 방지

- 템플릿 엔진이 대규모 타임스탬프 리터럴 파싱 시 자료형 표현 범위를 초과해 예외를 뱉는 버그를 포착했다.
- 템플릿 파일 내 하드코딩된 대규모 정수 리터럴에 64비트 자료형 접미사(L)를 강제 주입해, 포맷팅 파서가 오버플로우 없이 안전 취급하도록 로직을 수정했다.
- 본 조치로 대량 분석 보고서 일괄 생성 도중 산발하던 형변환 예외를 억제하고 파이프라인 무단 중단 이슈를 근본적으로 차단했다.
