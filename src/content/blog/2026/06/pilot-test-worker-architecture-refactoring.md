데이터베이스 병목을 해소하고 분석 파이프라인 처리 속도를 끌어올리기 위해 백엔드 구조를 개편했다. 고부하 계산 로직을 전용 워커로 이관하고 상태 기반 이벤트 필터링 아키텍처를 새로 수립했다.

## [Java / Architecture] 심층 분석 사전 검증 및 대량 처리 파이프라인 분리

- 통계 계산과 데이터 무결성 검증을 묶어서 처리해 구조적 결합도가 지나치게 높았던 기존 분석 서비스 체계를 해체했다.
- 사전 검증 로직 전담 컨트롤러와 서비스를 분리 독립시켜 책임 소재를 뚜렷하게 가르고, 비디오 스캔 완료 시점 즉시 검증이 트리거되도록 파이프라인을 재설계했다.
- 분석 타겟 매핑 로직 내 PostGIS 연동 기능을 추가해 공간 데이터 무결성과 정합성을 완벽히 확보했다.
- 속도가 저열한 기존 단건 쿼리 순회 방식을 폐기하고 JdbcTemplate 기반 일괄 분석 아키텍처를 전면 채택해 데이터 처리 성능을 끌어올렸다.

## [Rust / Analytics Worker] 이벤트 상태 머신 및 인메모리 집계 이관

- 심층 분석 도중 서버와 데이터베이스 간 잦은 쿼리 왕복으로 촉발되던 레이턴시 이슈를 해결했다.
- 위험 구간 시작점과 종료점을 정교히 식별하고자 내부 상태 머신(Idle -> Active -> Muted) 체계를 도입해 파편화된 이벤트 필터링을 안정적으로 소화하도록 다듬었다.
- 종전 Java 서비스 레이어가 버거워하던 차량 주행 및 감지 요약 등 고부하 통계 계산 로직을 고성능 Rust 워커 인메모리 수학 모듈로 전량 이관했다.
- 로직 이관을 통해 중간 계산 산출물을 데이터베이스에 기록하는 무의미한 I/O 비용을 날리고, 최종 압축 결과만을 gRPC 통신으로 회신하는 초단기 파이프라인을 완성했다.

## [Java / API] 고정밀 레이더 좌표 연산 및 텔레메트리 쿼리 개선

- 객체 상대 위치 추적 시 프론트엔드에 편중되던 계산 부하와 클라이언트 간 좌표 불일치 결함을 시정했다.
- 단순 중심점 투영 공식을 내리고 박스 레이 캐스팅 기법을 도입해, 객체의 정밀 발 좌표를 백엔드 워커 선행 연산 후 InfluxDB 시계열 데이터베이스로 직행 저장하도록 구조를 개선했다.
- InfluxDB에 적재된 2차원 평면 좌표를 부가 연산 없이 클라이언트에 쏘아주는 전용 API 엔드포인트를 구축해 프론트엔드 3D 좌표 변환 오버헤드를 뿌리 뽑았다.
- 복수 타겟 일괄 분석 수행 시 이미 처리가 끝난 타겟 결과 데이터를 인메모리 캐싱해 중복 계산을 철저히 막고 최종 가중 평균 병합 알고리즘 효율을 극대화했다.
