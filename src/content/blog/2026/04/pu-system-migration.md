장비마다 다른 기준 전압과 용량을 통일된 수치로 다루기 위해 전체 `models` 컴포넌트를 Per-Unit(PU) 단위계로 마이그레이션했다. 임피던스 계산 로직 중복을 차단하기 위해 스케일링 산식을 중앙 `BaseSystem`으로 집중시켰다.

## 전력 시스템 단위계 표준화 및 임피던스 반환 로직 개편

- `BaseSystem` 클래스 내 기준 임피던스 산출식을 순수한 `V^2 / P` 형태로 수정하고, 하드코딩된 레거시 10.0 스케일링 계수를 완전히 제거했다.
- `Line` 객체 생성자에 공칭 전압 매개변수를 추가하고, 어드미턴스와 임피던스 반환 시 사전 계산된 시스템 기준 임피던스(`z_base`)로 나누어 제공하도록 수정했다.
- `Transformer`, `PowerSource`, `Capacitor`, `Reactor` 등 파생 모델 임피던스 반환 로직을 단순 물리량 출력에서 시스템 기준 용량을 참조하는 PU 스케일링 방식으로 전면 개편했다.
- 계산 단위 혼동을 유발할 여지가 있는 백분율 임피던스(`percentImpedance`) 관련 메서드를 일괄 제거해 값 단위를 수학적으로 일원화했다.
- `Load` 클래스 내 유효·무효 전력 반환 함수가 시스템 기준 전력으로 나눈 PU 스칼라 값을 제공하도록 수식을 갱신했다.
- 전체 컴포넌트 통합 테스트 환경 내 구형 물리량 단위 판별 로직을 삭제하고 1.0 스케일 기준 정밀도 비교 방식(`EXPECT_NEAR`)으로 검증 체계를 재구축했다.
