고주파 텔레메트리 데이터 분석으로 운전자 전방 인지 및 회피 반응 시간(PRT, Perception-Reaction Time)을 도출하는 심층 분석 엔진을 도입했다. 센서 샘플링 레이트로 단일 물리 조작이 수백 개 독립 이벤트로 과다 계측되는 통계 왜곡을 바로잡고자 시계열 이벤트 클러스터링 아키텍처를 적용하고 결측치 보정 로직을 구현했다.

## [Data Analysis / Domain] 운전자 인지-반응 시간(PRT) 상태 전이 모델 구축

- 전방 위험 객체 탐지 시점부터 브레이크 조작 및 회피 조향으로 이어지는 반응 딜레이를 산출하고자 상태 전이 분석 파이프라인을 설계했다.
- 방대한 시계열 데이터 스캔 시 수반되는 메모 메모리 오버헤드를 줄일 목적으로 데이터베이스 레벨 차분 연산을 활용해, 가속 페달 개도량 등 물리적 엣지 트리거 시점을 정확히 포착했다.
- 유의미한 회피 기동을 필터링하도록 조향 각속도, 요레이트, 횡가속도 등 동역학 임계치 기준을 확립해 분석 엔진 객관성을 확보했다.
- 단시간 내 연속 발생하는 다발성 위험 알람을 단일 에피소드로 논리 그룹화하는 타임 윈도우 알고리즘을 적용했다.

## [Java / Architecture] 하트비트 기반 시계열 이벤트 클러스터링

- 초당 수십 프레임 단위로 유입되는 고주파 페달 및 조향 데이터를 단순 집계할 때 생기는 과계측 현상을 해결하고자, 이벤트 간격을 분석해 단일 액션으로 병합하는 클러스터링 알고리즘을 애플리케이션 계층에 구현했다.
- 레거시 하드웨어 데이터 규격이 낳는 스키마 불일치 에러를 회피하기 위해 데이터베이스 네이티브 기능 대신 인프라 종속성이 낮은 독자적 클러스터링 로직으로 선회했다.
- 엣지 디바이스 통신 불안정에 따른 데이터 결측 상황에서도 물리 조작 이벤트가 정상 병합되도록, 네트워크 하트비트 주기를 고려한 클러스터링 임계값을 설정해 통계 분석 신뢰도를 향상했다.

## [API / Schema] 동적 스키마 버저닝 및 하위 호환성 확보

- 특정 시점 기점으로 비전 센서 위험도 판단 체계가 변경된 펌웨어 버전 파편화 이슈를 식별했다.
- API 요청 조회 타임스탬프 기준으로 센서 펌웨어 스키마 버전을 판별하고, 시계열 쿼리에 동적 호환 매핑 상수를 주입하는 하위 호환성 보장 로직을 도입해 과거 데이터와 최신 데이터를 단일 파이프라인에서 정합성 있게 분석할 기반을 구축했다.
