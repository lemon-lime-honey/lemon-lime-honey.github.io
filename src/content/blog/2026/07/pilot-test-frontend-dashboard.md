프론트엔드 시스템은 차트 렌더링에 따른 메인 스레드 블로킹 문제와 비대해진 모달 컴포넌트의 상태 관리 복잡도를 안고 있었다. 이를 해결하기 위해 병렬 처리 워커를 도입하고 모달의 역할을 훅 기반으로 분리하여 컴포넌트 응집도를 향상시켰다.

## [TypeScript / Web Worker] 백그라운드 데이터 연산

- 브라우저 메인 스레드에서 대량의 통계 데이터에 대한 커널 밀도 추정 연산을 수행하여 UI 렌더링이 지연되었다.
- 브라우저의 백그라운드 스레드에서 동작하는 전용 웹 워커를 생성하여, 메인 스레드에 병목을 유발하던 무거운 수학적 연산을 전면 위임했다.
- 무거운 연산이 비동기로 처리되는 동안 사용자에게 차트 렌더링 대기 상태를 직관적으로 알리는 로딩 오버레이를 구현했다.
- 백그라운드 연산이 완료된 후 리액트 상태를 한 번에 업데이트하여 화면이 버벅거리거나 끊기는 현상 없는 매끄러운 차트 시각화를 달성했다.

## [React / Component] 다목적 분석 모달 로직 분리

- 분석 상세 모달 컴포넌트 내부에 영상 재생, 키보드 단축키, 태그 편집 등 수많은 상태와 비즈니스 로직이 혼재했다.
- 모달 내부에 혼재되어 있던 태그 편집 상태와 각종 이벤트 핸들러를 별도의 커스텀 훅으로 빼내어 데이터 변경 로직을 깔끔하게 추출했다.
- 영상 재생 제어, 스크롤 동기화, 단축키 처리 등 UI와 무관한 제어 로직들을 별도의 동기화 전용 훅으로 완벽히 분리했다.
- 비즈니스 로직을 모두 덜어낸 모달 컴포넌트는 순수하게 전달받은 상태를 바탕으로 UI를 렌더링하는 역할만 수행하도록 책임을 분배하고 코드를 경량화했다.

## [React / Event System] 계층형 이벤트 필터링

- 분석 대상 이벤트를 조회할 때 단순 조건 검색만 가능하여 다양한 태그 조합을 통한 맥락 검색이 불가능했다.
- 보행자 상태, 가시성, 비고 등 새롭게 확장된 메타데이터를 기반으로 사용자 조건을 입력받는 다중 드롭다운 셀렉터를 구현했다.
- 단순 평면 목록이던 이벤트 목록을 계층형 트리 구조로 재구성하고, 여러 태그를 동시 선택할 때 교집합 기반의 정밀한 검색이 가능하도록 내부 상태 관리를 최적화했다.
- 수많은 이벤트를 필터링할 때 발생하는 데이터 로딩 성능 저하를 방지하기 위해, 전체 선택 토글 및 필터링 적용 알고리즘을 고도로 효율화했다.

## [React / Data Export] 데이터 추출 유틸리티

- 차트로 렌더링된 데이터를 외부에서 교차 검증하거나 보고서로 활용할 수 있는 수단이 없었다.
- 사용자가 설정한 규칙과 일치하는 반응 시간 데이터를 파싱하여 외부 활용이 가능한 CSV 등의 텍스트 포맷으로 변환하는 전용 내보내기 모듈을 작성했다.
- 엑셀 등 외부 프로그램에서 파일을 열 때 텍스트가 깨지는 문자 인코딩 호환성 문제를 방지하기 위해, 출력 바이트 스트림의 시작부에 BOM(Byte Order Mark)을 명시적으로 추가했다.
- 사용자가 내보내기 기능을 쉽게 찾을 수 있도록 차트 패널 최상단 툴바에 직관적인 다운로드 트리거 버튼을 추가하여 접근성을 확보했다.
