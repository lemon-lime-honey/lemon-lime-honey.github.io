프론트엔드 시스템은 차트 렌더링으로 촉발되는 메인 스레드 블로킹 이슈와 비대해진 모달 컴포넌트의 상태 관리 복잡도를 안고 있었다. 이를 해소할 목적으로 병렬 처리 워커를 도입하고 모달의 역할을 훅 기반으로 쪼개 컴포넌트 응집도를 끌어올렸다.

## [TypeScript / Web Worker] 백그라운드 데이터 연산

- 브라우저 메인 스레드가 대량 통계 데이터 대상 커널 밀도 추정 연산까지 짊어지며 UI 렌더링 지연이 발생하는 현상을 시정했다.
- 브라우저 백그라운드 스레드에서 구동하는 전용 웹 워커를 투입해, 메인 스레드 병목의 주범이던 헤비한 수학적 연산을 전량 위임했다.
- 무거운 연산이 비동기 처리되는 막간을 이용해 차트 렌더링 대기 상태를 직관적으로 표출하는 로딩 오버레이를 가미했다.
- 백그라운드 연산이 종료된 후 React 상태를 일괄 업데이트함으로써 프레임 드랍이나 버벅임 없는 유려한 차트 시각화를 달성했다.

## [React / Component] 다목적 분석 모달 로직 분리

- 분석 상세 모달 컴포넌트 내부에 영상 재생, 키보드 단축키, 태그 편집 등 다종다양한 상태와 비즈니스 로직이 난립하던 구조를 정돈했다.
- 모달 내부에 어지럽게 얽혀 있던 태그 편집 상태와 제반 이벤트 핸들러를 독립된 커스텀 훅으로 들어내 데이터 변경 로직을 말끔히 추출했다.
- 영상 재생 제어, 스크롤 동기화, 단축키 처리 등 UI와 무관한 제어 로직을 별도 동기화 전용 훅으로 완벽히 격리했다.
- 비즈니스 로직을 모두 탈각한 모달 컴포넌트는 순수히 주입받은 상태를 바탕으로 UI만 렌더링하도록 책임을 재분배해 코드를 경량화했다.

## [React / Event System] 계층형 이벤트 필터링

- 단순 조건 검색에만 머물러 다중 태그 조합형 맥락 검색을 옥죄던 기존 이벤트 조회 체계를 갈아엎었다.
- 보행자 상태, 가시성, 비고 등 신규 확장 메타데이터를 근거로 사용자 입력 조건을 접수하는 다중 드롭다운 셀렉터를 탑재했다.
- 단순 평면 구조이던 이벤트 목록을 계층형 트리 구조로 탈바꿈시키고, 여러 태그 중복 선택 시 교집합 기반 정밀 검색이 구동되도록 내부 상태 관리를 최적화했다.
- 방대한 이벤트를 필터링할 시 불거지는 데이터 로드 성능 저하를 방어하고자, 전체 선택 토글 및 필터링 알고리즘 효율을 고도로 다듬었다.

## [React / Data Export] 데이터 추출 유틸리티

- 차트로 표출된 데이터를 외부에서 교차 검증하거나 보고서로 인용할 마땅한 수단이 없던 한계를 보완했다.
- 사용자가 지정한 룰과 부합하는 반응 시간 데이터를 파싱해 외부 활용이 용이한 CSV 등 텍스트 포맷으로 뱉어내는 전용 내보내기 모듈을 작성했다.
- 엑셀 등 서드파티 프로그램에서 파일 개방 시 문자가 깨지는 인코딩 호환성 결함을 막고자, 출력 바이트 스트림 서두에 BOM(Byte Order Mark)을 명시적으로 박아 넣었다.
- 사용자가 내보내기 기능을 쉽게 짐작할 수 있도록 차트 패널 최상단 툴바 구역에 직관적 다운로드 트리거 버튼을 배치해 접근성을 높였다.
