주행 궤적 데이터 기반 운전자 반응 분석 알고리즘의 한계를 돌파하고자 Rust 기반 고성능 연산 워커를 새로 투입했다. 고난도 수치 연산 로직을 백엔드에서 워커로 떼어내고, 대규모 이벤트 일괄 분석을 감당할 비동기 처리 파이프라인을 구축했다.

## [Rust / Kinematics] 시계열 궤적 필터링 및 변동점 탐지

- 원시 주행 데이터 내 유의미한 반응 시점을 짚어내는 과정이 불안정하던 징후를 포착했다.
- 시계열 궤적에 Kalman RTS Smoother를 적용해 노이즈가 낀 차량 데이터를 보간했다.
- 임계값 기반 단순 비교에 의존하던 기존 로직을 걷어내고 연속 구간 선형 회귀 알고리즘을 도입해, 운전자 반응 변동점을 수학적으로 정밀하게 타겟팅했다.
- 복잡한 부동소수점 연산 도중 야기될 수 있는 자릿수 상실 결함을 막고자, 경고 시점을 영점으로 잡는 상대 시간 변환 기법을 곁들였다.

## [Rust / Statistics] 대용량 밀도 추정 엔진

- Java 기반 임시 연산이나 프론트엔드 워커에 기댄 탓에 대용량 분포 데이터 처리에 한계가 뚜렷했던 상황을 타개했다.
- 자체 교차 검증을 수행해 최적 대역폭을 스스로 뽑아내는 고성능 커널 밀도 추정 모듈을 Rust 생태계로 전량 이관했다.
- 방대한 차량 동적 반응 지연 분포 및 속도 프로파일을 Rust 워커에서 초고속 연산한 뒤, gRPC 통신으로 백엔드에 안전 반환하도록 구현했다.
- 데이터 수집 중 필연적으로 섞여 드는 누락 값을 탈 없이 우회하고자 Protobuf의 Optional 필드 매핑 기능을 적극 활용했다.

## [Java / Asynchronous] 이벤트 비동기 배치 처리

- 다수 이벤트를 동기식으로 일괄 분석 시 클라이언트 연결이 끊어지는 타임아웃 셧다운 문제를 시정했다.
- 장시간이 요구되는 대규모 분석 요청 시 HTTP 202 Accepted 응답을 선제 반환하도록 설계해 프록시 계층 타임아웃 오류를 차단했다.
- 분석 요청을 넘겨받은 백그라운드 스레드풀이 타겟 이벤트를 순차적으로 안전 취급하고, 개별 이벤트 처리 상태를 데이터베이스에 즉각 반영하도록 구현했다.
- 단방향 통신 규격인 SSE 채널을 개설해, 클라이언트 대시보드 측에 실시간 진행률 및 분석 작업 상태를 끊김 없이 스트리밍했다.

## [PostgreSQL / Persistence] 시계열 배열 데이터 바이너리 직렬화

- 동역학 분석 결과로 양산되는 거대한 궤적 데이터를 관계형 테이블에 생으로 밀어 넣기에 부적합하던 스키마 구조를 손봤다.
- 데이터베이스 스토리지 점유량을 최적화할 목적으로 방대한 시계열 부동소수점 배열을 바이트 스트림으로 압축해 바이너리(BYTEA) 컬럼에 욱여넣었다.
- 바이너리로 뭉쳐진 궤적 데이터와는 별개로 검색·정렬 빈도가 잦은 핵심 지표는 물리 테이블 컬럼으로 쪼개내어 빠른 쿼리 스캔을 뒷받침했다.
- 분석 주체인 이벤트 레코드 삭제 시, 데이터베이스 외래 키 제약 조건(ON DELETE CASCADE)에 의해 연관 거동 지표와 동역학 데이터가 찌꺼기 없이 동반 소거되도록 제약을 단단히 걸어두었다.
