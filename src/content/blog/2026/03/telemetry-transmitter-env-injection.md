로컬 테스트 및 운영 서버 배포 환경의 상이함을 제어하기 위해 설정 파일 로딩 구조를 변경했다.

## [Configuration / Env] 전역 환경 변수 치환 로직 도입

- 설정 파일 파싱 직전 `envsubst` 유틸리티를 활용해 설정 파일 내 템플릿 변수를 호스트 실제 환경 변수로 일괄 치환하는 전처리 단계를 추가했다.
- 코드 레벨에서 개별 필드를 수동 확장하던 분기 로직을 모두 제거해 설정 파일 파싱 안전성을 개선했으며, 릴리스 유지보수 오버헤드를 감소시켰다.
