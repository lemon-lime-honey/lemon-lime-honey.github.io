주 전원과 전압 변환 장치 표현 모델을 추가하고, 시스템 전역 물리 단위계를 사용하기 위해 기준 임피던스 연산 로직을 싱글톤 아키텍처로 통합했다.

## 전원 및 변압기 단락 용량 기반 임피던스 도출

- `PowerSource` 객체를 설계해 외부 전원 및 주 발전기 단락 용량 데이터 기반 등가 내부 임피던스와 퍼센트 임피던스 도출 로직을 적용했다.
- 전원이 무한대 모선으로 동작하는 상황에 대비해, 단락 용량이 0 이하로 입력되면 임피던스 0을 반환하도록 예외 처리(`if (shortCircuitCapacity_ <= 0.0)`)를 구현했다.
- 전압 변환 컴포넌트 `Transformer` 객체는 정격 용량, 1/2차측 전압, 퍼센트 임피던스 정보를 관리하며, 시스템 기준 용량 변동 시 퍼센트 임피던스를 동적 스케일링하는 수식을 적용했다.

## 중앙 단위계 및 공통 임피던스 산출 로직 캡슐화

- 시스템 전역 기준 주파수와 기준 전력을 저장·관리하도록 `BaseSystem` 싱글톤 객체를 적용했다.
- 기준 임피던스 산출 정규화 공식 `10.0 * voltage * voltage / power` 로직을 `getBaseImpedance()` 메서드로 캡슐화해 중복 코드를 제거했다.
- `Line`, `PowerSource`, `Transformer` 모델 내부 계산식을 리팩토링해, 임피던스 산출 시 `BaseSystem::instance()`를 호출하고 시스템 기준 주파수 및 기준 전력을 참조하도록 구조를 변경했다.
