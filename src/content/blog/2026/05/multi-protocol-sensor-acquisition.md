다중 통신 프로토콜 환경 내 동역학 센서 데이터 무결성을 확보하고 차량 상태 추론 엔진을 고도화했다. 차량 후진 상태 진입 시 발생하는 속도 및 궤적 오산출 문제를 해결하고자 판정 우선순위를 재설계하고 결측치 처리 정책을 정규화했다.

## [Data Pipeline / Filter] 동역학 센서 데이터 결측치(NA) 기준 정규화

- 차량 센서 데이터 파이프라인 상태 코드 명세 변경 사항에 동기화해 송신 엔진 필터링 규칙을 갱신했다.
- 주요 동역학 지표 중 서버 송신을 무시해야 할 결측치 필터링 기준을 내부 상태 머신 명세상 무효(INVALID) 규격에 맞춰 일괄 적용했다.

## [Inference Engine / Kinematics] 2-Tier Fallback 기반 기어 판정 파이프라인 구축

- 프로토콜별 상이한 기어 상태 정보(UDS, J1939 등)를 단일 추론 인터페이스에서 획득하도록 로직을 추상화했다. OBD 단자로 수집되는 Gear Selector, Current Gear, Commanded Gear 값을 통합 활용했다.
- 신뢰도가 높은 현재 기어 데이터를 1순위로 평가하고, 데이터 유실 혹은 프로토콜 미지원 시 변속기 레버 상태를 2순위로 참조하는 Fallback 구조를 설계해 후진 기어 감지 신뢰성을 제고했다.

## [Architecture / Logic] 상태 판정 우선순위 역전 및 제어 흐름 최적화

- 기존 동역학 추론 로직 내 속도 임계치 필터가 최상단에 위치해 저속 후진을 정차 상태로 오분류하거나 직진 궤적으로 누적하던 아키텍처 결함을 바로잡았다.
- 추론 엔진 상태 분기 제어 흐름을 전면 개편해, 기어 값을 참조한 후진 상태를 최우선 평가하도록 판정 우선순위를 역전시켰다.
- 후진 상태 진입 감지 즉시 누적 주행 거리 및 조향각 궤적 버퍼를 강제 리셋해 오염된 데이터가 후처리 파이프라인으로 유입되는 것을 차단했다.

## [Session Manager / Logic] 주행 궤적 기반 공간 메타데이터 자동 매핑

- 수동 매핑 방식 한계를 극복하고자 저장된 GPS 주행 궤적을 기반으로 세션당 방문 사고 다발지 및 경유 자치구를 자동 연산해 매핑하는 로직을 통합했다.
