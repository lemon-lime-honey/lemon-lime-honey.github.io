특정 차량 프로토콜이나 통신 식별자에 하드코딩된 기존 시스템의 한계를 해결하고, 다차종 통신 테스트를 진행하기 위해 설정 계층 의존성을 분리했다.

## [JSON / Configuration] 통신 식별자 및 페이로드 메타데이터 분리

핵심 로직 내부에 포함된 진단 요청 페이로드, 응답 식별자 등 주요 메타데이터를 외부 설정 파일(JSON)로 분리했다.

- JSON 설정 파일에 통신 식별자, 제어기 요청 메시지 포맷, 파싱 규격을 매핑하는 트리 구조를 정의해 런타임에 애플리케이션에 주입하도록 변경했다.
- 애플리케이션 재빌드 없이 JSON 설정 파일 수정만으로 여러 차량 제조사의 진단 통신망에 대응할 수 있도록 구조를 개선했다.
- 적용 결과 신규 차종 및 센서 테스트 시 발생하는 프로토콜 설정 변경 작업을 제거했으며, 수집 주기 최적화 모듈을 위한 변수 제어 환경을 구성했다.
