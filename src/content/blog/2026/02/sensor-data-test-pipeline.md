비표준 확장 PID 스캔 중 발생한 응답 데이터 누락 현상을 해결하고, 차량 네트워크 프로토콜(CAN-ISOTP)의 통신 안정성을 확인하기 위해 Python 기반 분석 파이프라인을 설계했다.

## [Python / Payload Parser] 원시 페이로드 역직렬화 및 단위 변환 계층

차량 네트워크에서 수신한 바이트 스트림과 헥사 코드 문자열을 물리적 단위로 변환하는 데이터 파싱 모듈을 추가했다.

- 비트 단위 분할 연산을 적용해 속도, 조향각 등 데이터 무결성을 유지하는 역직렬화 알고리즘을 구현했다.
- 주차 및 주행 환경에서 수집한 원시 페이로드 비트 패턴 변화를 분석해, 제동 계통 스위치 상태 판정 알고리즘을 수정하고 파싱 신뢰성을 개선했다.

## [Tkinter / SQLite] 사용자 인터페이스 및 테스트 검증

현장 테스트 중 통신 상태와 파싱 결과를 모니터링하기 위한 디버깅 전용 사용자 인터페이스를 구성했다.

- Python GUI 프레임워크 Tkinter를 사용해, 차량 내부 테스트 시 실시간 통신 로그를 확인하는 대시보드를 구축했다.
- 단위 테스트 수집 결과를 날짜별로 분리된 SQLite 로컬 데이터베이스 파일에 저장하는 자동화 로직을 추가했다.
- 수집 세션 단위로 데이터베이스 테이블이 생성되도록 구성해 데이터 일관성을 유지했으며, 시계열 결과를 로컬 디렉토리에 저장해 검증 단계를 개선했다.
